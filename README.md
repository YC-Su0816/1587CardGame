# 遊戲規則
## 背景故事
打從2022年，1587班的成員們見到彼此，一場無形的角力便在這群同學之間悄悄蔓延。大家各個都是國中時期的英菁，自然想要把彼此都除掉，成為唯一活著走出教室的人，因此這三年，所有人無所不用其極，用盡所有手段坑害彼此，把1587教室變成腥風血雨的戰場......

## 遊玩機制
和《God Field》差不多，惟本遊戲在舊有的基礎下，修改了部分機制
* 出牌&抽牌：每次出牌時，預設可以抽回一張牌(不管是攻擊、防禦，也不管出幾張，就是抽到一張牌)，手牌的上限為20張。strengthen可配合attack/multiattack打出，defense可疊加打出，其餘卡牌一次僅限打出一張。輪到自己的回合，可選擇打出手牌或是直接抽一張牌。所有卡牌為機率抽出，卡牌數量並非有限。
* 角色&技能：本遊戲目前有30位電神們，於進入「教室」前可於三位隨機角色中選擇一位做為該輪遊戲的身分，每位角色都有略有差異的數值、有特色的被動技能與獨特的主動技能，使得校園變得更加刺激。
* 勝負條件：本遊戲有三項數值：智慧、體力與聲譽。如同在學校(社會)裡生存，三項數值同等重要。畢竟Thread上有人說過，「你不能成績也爛，遊戲也差」，本遊戲在任兩數值歸0後判定為(社會性)死亡，不得繼續參與後續的出牌。
* 數值計算：
    * 所有攻擊為負值，治療為正值，防禦為正值。
    * 於出牌階段，系統顯示該牌原始的數值。
    * 確認出牌後，系統將計算完的數值顯示於第一張牌下方，計算方式為：ceiling(數值加總×角色倍率)＋角色加成
* 卡牌分類：本遊戲有7種卡牌
    * attack：單體攻擊
    * multiattack：群體攻擊
    * defense：攻擊類防禦（包含反彈）
    * medicine：恢復類
    * strengthen：強化攻擊
    * special：各種特殊卡牌
    * effect：效果顯示，不列入卡池
* 勝利條件：當除了自己以外的玩家全部(社會性)死亡，你即為勝利者。

# 如何協助

你的任務是幫這個遊戲生成各種創意卡牌。但畢竟場地是在1587的教室，所以請盡量採用與附中或科學班有關的元素。當然，這只是建議，你要把【危險的杵】搬進來我也沒意見。

## 新增一張non-special的卡牌
假設你要新增檔案名稱為demo的卡片，你要做三件事
### 0.卡片數值的要求
本遊戲暫不打算壓制攻擊/防禦/治療上限，但對於各類卡牌的作用量有一定要求
* 攻擊類卡牌：
  * 其造成傷害總量需比治療總量至少多出5，單一傷害量勿超出30點，傷害總量勿超出60點。(其實這已經是相當可怕的量了，ex. 參閱「宥鈞」的被動「大起大落」，30點的傷害乘上三倍...核彈阿)
  * 避免數值過於膨脹，為將來的平衡性調整帶來麻煩，請不要一股腦地做出一個又一個核彈級別的卡，多數卡牌的數值請保持在各項數值皆在15點以下，總量不超出30點
  * 此外，若製作群攻卡牌，請更加的節制。盡量避免出現神界裡面「黑洞」這種大殺器。
* 防禦類卡牌：
  * 其造成防禦總量需比犧牲總量至少多出5，單一防禦量勿超出35點，防禦總量勿超出70點。
  * 避免數值過於膨脹，為將來的平衡性調整帶來麻煩，請不要一股腦地做出一個又一個金庫級別的卡，多數卡牌的數值請保持在各項數值皆在20點以下，總量不超出30點
* 藥品類卡牌
  * 其造成治療總量需比傷害總量至少多出8，單一治療量勿超出20點，治療總量勿超出50點。
  * 避免數值過於膨脹，為將來的平衡性調整帶來麻煩，請不要一股腦地做出一個又一個華佗級別的卡，多數卡牌的數值請保持在各項數值皆在15點以下，總量不超出30點
* 強化類卡牌
  * 其造成傷害增量不得少於傷害減量(所有數值加總≦0)，單一增加量勿超出15點，增加總量勿超出30點。
  * 避免數值過於膨脹，為將來的平衡性調整帶來麻煩，請不要一股腦地做出一個又一個...我沒有形容詞了...級別的卡，多數卡牌的數值請保持在各項數值皆在10點以下，總量不超出20點 
### 1.上傳這張卡牌在遊戲中的資訊
卡牌的介紹為.txt檔，格式為
```
<智力數值>(負數是傷害，正數是恢復，0代表沒有這方面的效果)
<體力數值>
<聲譽數值>
卡牌名稱(10字以內)
卡牌簡介(15字以內)
```
會是一個有五行的.txt檔。前三行為數字，後兩行可以是中文、英文、日文。
例如
```
1
0
-6
倚天屠龍劍
為了示範而寫的，不存在的武器
```
檔名必須是demo.txt，存在/Assets/Resources/text/Tool/對應類別/ 裡面。

### 2.上傳這張卡牌在遊戲中的顯示
請上傳大小在400x400以內的正方形.jpg檔，其實越小越好啦
檔名必須是demo.jpg，存在/Assets/Resources/image/Tool/對應類別/ 裡面。


### 3.將此卡加入對應類別的卡池中
在/Assets/Resources/pool/對應類別.txt 中加入demo並換行。
```
...前面有不少行
demo
```

## 新增一張special的卡牌

假設你要新增檔案名稱為demo的卡片，你要做四件事
### 1.上傳這張卡牌在遊戲中的資訊
卡牌的介紹為.txt檔，請簡要介紹這張牌在遊戲中的名字，會賦予什麼效果(ex：虛弱？直接出局？)，他是屬於永久存在(需要其他卡牌來消除效果)還是指定回合後會消失？。我和Gemini會想辦法把他實踐出來XD，除非太過天方夜譚(ex. Remove OS)。  
請在/Assets/Resources/text/Effect/Special_discription.txt 裡新增效果介紹，並通知作者，待作者審核後，會告訴你此效果排可否實作。  
(我~忘記~懶得改資料夾名字了，將就一下吧)  
可以實作才需要到後面三個步驟

### 2.上傳這張卡牌在遊戲中的資訊
卡牌的介紹為.txt檔，格式為
```
卡牌名稱(10字以內)
卡牌簡介(15字以內)
卡牌效果(15字以內)
```
會是一個有三行的.txt檔，可以是中文、英文、日文。
例如
```
凋零I
從Minecraft混入的效果
直接出局
```
檔名必須是demo.txt，存在/Assets/Resources/text/Tool/special/ 裡面。

### 3.上傳這張卡牌在遊戲中的顯示
請上傳大小在400x400以內的正方形.jpg檔，其實越小越好啦
檔名必須是demo.jpg，存在/Assets/Resources/image/Tool/special/ 裡面。


### 4.將此卡加入對應類別的卡池中
在/Assets/Resources/text/Tool/special.txt 中加入三行。**這裡很特別**，請用boolean標註能否在自己的回合出此張牌，能否打出這張牌作為回應，以及對方能不能回應。之間以英文逗點隔開，不用空格。
```
...前面有不少行
demo,false,true,false
```
例如這樣代表demo不能主動打出，但可作為回應牌使用，對方不可回應。

此外，/Assets/Resources/text/CCard/ 裡面有30位電神的技能介紹與數值，前三行對應代三項數值，第四、五行是被動技能的名稱與內容，第676767676767行是主動技能的名稱和內容，第八行是主動技能的冷卻時間，如果有不滿意或者是有任何建議都可以提，我不會聽。好啦我會改:3
