# 1587CardGame
A card game which directly mimics "God Field" without concerning copyright. I guess that copyright means "Copying is the right thing to do."

# 關於此遊戲
打從2022年，1587班的成員們見到彼此，一場無形的角力便在這群同學之間悄悄蔓延。大家各個都是國中時期的英菁，自然想要把彼此都除掉，成為唯一活著走出教室的人，因此這三年，所有人無所不用其極，用盡所有手段坑害彼此，把1587教室變成腥風血雨的戰場......

## 遊玩機制
和《God Field》差不多，惟本遊戲在舊有的基礎下，修改了部分機制

* 角色：目前有30位電神們，於進入「教室」前可於三位隨機角色中選擇一位做為該輪遊戲的身分，每位角色都有**略有差異的數值**、**有特色的被動技能**與**獨特的主動技能**，使得校園變得更加刺激。
    * 角色死亡：本遊戲有三項數值：**智慧**、**體力**與**聲譽**。如同在學校(社會)裡生存，三項數值同等重要，只要**歸零就無法再回復**。畢竟Threads上有人說過，「你不能成績也爛，遊戲也差」，本遊戲在**任兩數值歸零**後判定為(社會性)死亡。
    * 效果：遊戲內有沉睡、失神等效果，可以透過卡牌、主動即被動效果附加。

* 玩家回合：若玩家沒有跳過回合的效果，就可以進行回合，分成出牌、防禦與回應、抽牌，在主動技能允許發動的情況可以使用主動技能。

    * 出牌：在出牌階段，玩家可以選擇使用攻擊、回復或特殊牌，或是使用符合在出牌階段使用的主動技能，也可以不出牌或棄牌。
        * 攻擊：單體攻擊牌可以搭配強化攻擊一起使用，群體攻擊則不可以搭配強化攻擊使用，攻擊牌限制出牌上限為1張，強化攻擊無使用上限。
        * 回復：回復牌出牌上限為1張，可以選擇目標為自己或他人。
        * 特殊：特殊牌出牌上限為1張，除部分例外，可以選擇目標為自己或他人。
        * 使用主動技能：造成攻擊、回復的主動技能與視作為出牌的技能，會導致攻擊階段結束，視做出牌的技能在自身回合結束後**不能抽牌**。
        * 不出牌：在牌桌上無要出的牌時確認，視同不出牌，在自身回合結束後抽1張牌。
        * 棄牌：透過切換鍵選擇多張要棄出的牌，棄牌後視同結束回合，在自身回合結束後**不能抽牌**。

    * 防禦與回應：當你受到攻擊或被施加狀態時，你可以做出防禦或回應，或是使用允許在受擊情況發動的主動技能。
        * 防禦：可以使用防禦卡使得攻擊卡對應的**智慧**、**體力**與**聲譽**傷害量減少，防禦卡的數值可疊加，防禦卡的數量沒有限制。
        * 應對回復：可以使用**無視**卡牌使回復無效。
        * 應對被施加狀態：可以使用**無視**卡牌使施加狀態的卡無效。
        
    * 抽牌：在自身回合結束時，若尚未達到手牌上限，可以抽一張牌，手牌上限為**20張**。

* 卡牌：本遊戲有5種卡牌，分為以下幾種

    * 攻擊：分為單體與群攻，可以對玩家造成攻擊，分為**智慧**、**體力**與**聲譽**三項傷害，單體攻擊牌可以搭配強化攻擊一起使用，群體攻擊則不可以搭配強化攻擊使用，攻擊牌限制出牌上限為1張。
    * 防禦、反彈：可以使用防禦所受的攻擊使對應的傷害量減少，防禦卡的數值可疊加，防禦卡的數量沒有限制。
    * 恢復：恢復自身或他人的**智慧**、**體力**與**聲譽**，已經歸零的數值無法被恢復。
    * 強化攻擊：可以與**單體**攻擊牌搭配使用，智慧、體力與聲譽的傷害分別計算，傷害可以疊加。
    * 特殊：可以對自己或他人造成效果，詳細見卡牌介紹。

* 勝利條件：當除了自己以外的玩家全部(社會性)死亡，你即為勝利者。
